Zendesk tag retag scripts (generated by Lasso's Tag Normalizer)
================================================================

tag_changes.csv lists each tag to retire (old_tag) and the tag that replaces
it (new_tag). Review and edit it before running anything: delete a row to
leave that tag alone.

Needs Python 3.8+ and nothing else. Run from this folder, in order:

    export ZENDESK_SUBDOMAIN=yourcompany
    export ZENDESK_EMAIL=agent@example.com
    export ZENDESK_API_TOKEN=...

    python 1_find_tickets.py              # read-only: writes tickets_to_retag.csv
    python 2_remove_old_tags.py           # dry run: shows what it would remove
    python 2_remove_old_tags.py --apply   # removes old_tag from those tickets
    python 3_add_new_tags.py              # dry run
    python 3_add_new_tags.py --apply      # adds new_tag to the same tickets

Notes
- Steps 2 and 3 work from tickets_to_retag.csv, not a fresh search, so the
  tickets that lose old_tag in step 2 are the ones that gain new_tag in step
  3. Keep that file until step 3 has finished. If step 3 is interrupted,
  just run it again: adding a tag twice changes nothing.
- Only the named tag is removed or added; each ticket's other tags stay.
- Closed tickets can't be updated in Zendesk, so they are listed but skipped.
- Each change is a normal ticket update: it changes updated_at and can fire
  triggers or automations that look at tags. Check those for the old and new
  tags first, and consider running in a sandbox (ZENDESK_BASE_URL) first.
- Results, including any failures, are written to 2_remove_results.csv and
  3_add_results.csv.
