# Lasso v2.0.2

**Lasso v2.0.2 reads an Aha idea's main page as reviewer evidence.** Before, only the History tab was read properly.

## What's new since v2.0.1

### Decision Engine: reviewer evidence
- **Aha main pages:** an idea's main page, printed to PDF or copied as text, is now read as its own kind of page.
  - **Before:** it was read as a History page with no history. Its description ran to the end of the page and took in the sidebar, a proxy voter's email, and the related-ideas tables with *other* ideas' statuses. All of that went to the arbiter as this idea's description. Long titles were cut off at the line break.
  - **Title and description:** the full title, and the description on its own.
  - **Sidebar:** status, assignee, workspace, categories, themes, tags, product value and visibility.
  - **Merged into:** the idea it was merged into, if any. The evidence summary shows it too, for example "Aha LAPIPLAT-I-662: Add Video to Feedback Aide Sources (Parked, merged into FA-I-21)".
  - **Counts:** merged ideas, linked records, and the vote box's totals.
  - **Zendesk ticket and requester:** the ticket number and the customer and org, from Support's "Opened on behalf of … Ticket created from #…" wording.
  - **Related ideas:** the ideas in Similar ideas and People also voted for, each with its name, status and votes. A note tells the model their statuses are not this idea's.
  - **Safe pairing:** the PDF prints these tables a column at a time. A table whose columns don't pair up exactly keeps its references, but without names or statuses.
  - **History tab:** the main page has no comments or workflow history. Its evidence says they're on the History tab.
- **History pages** are read as before. Their evidence is now marked `page: history`, and a main page's `page: idea`. Add both pages to a case for an idea's full record.

## Upgrading from v2.0.1

- **Evidence already added** keeps what was read when it was added. To pick up the new fields, add an idea's main page to the case again.
- **No new settings, dependencies or collections.**

## Known issues

- **No Aha link:** the main page doesn't print the idea's link, so its evidence has none.
- **Missing table rows:** a related-ideas row whose status prints run into its name is left out.
- **No ticket check:** the Zendesk ticket an idea names isn't checked against the case's ticket, since one idea can serve several tickets.
- **Unchanged from v2.0.1:** see the v2.0.1 and v2.0.0 notes.
